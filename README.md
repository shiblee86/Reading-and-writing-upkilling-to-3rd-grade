# 🌙 Reading & Writing Park

A complete reading comprehension app for grades K-3 featuring vocabulary, sequencing, and comprehension passages.

## 🎮 Features

- **1st Grade**: Simple vocabulary, basic sequencing, short stories
- **2nd Grade**: Compound words, synonyms, antonyms, homophones, longer passages
- **3rd Grade**: Figurative language, prefixes/suffixes, context clues, inferences
